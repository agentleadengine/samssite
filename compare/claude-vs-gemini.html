Claude vs Gemini

Compare the current API families, data controls, and one repeatable business task.

My verdict: I start with Claude when long-document review and a controlled agent build are central. I start with Gemini when Google Workspace fit or the current Flash price matters. I still test both on the actual task.

Claude Fable 5.1, Opus 5.5, and Sonnet 5 list 1 million tokens of context and 128,000 maximum output. Haiku 4.5 lists 200,000 and 64,000.

Checked28 Sep 2026Source 01

Claude API prices per million tokens are Fable 5.1 at $10 input and $50 output, Opus 5.5 at $4 and $20, Sonnet 5 at $2 and $10, and Haiku 4.5 at $1 and $5.

Checked28 Sep 2026Source 02

Gemini 3.8 Flash is $0.75 input and $3.75 output per million tokens through 31 Dec 2026. The listed rate changes on 1 Jan 2027.

Changing28 Sep 2026Source 03

Claude commercial API, Team, and Enterprise data is not used for training unless the organization opts into a separate program.

Checked28 Sep 2026Source 04

Consumer Gemini activity follows the Keep Activity setting. Workspace data follows Workspace terms instead.

A reproducible task matrix

Use 20 anonymized customer questions and one approved policy document. Score exact extraction, citation support, refusal when the answer is missing, tool-call arguments, latency, and token cost. Keep temperature, retry count, and prompt text the same.

PromptAnswer from the policy only. Cite the section heading. If the policy does not answer the question, return {"status":"needs_review","reason":"missing policy support"}. Do not infer a rule.

The limitation is simple: a larger context window does not guarantee better use of the middle of a document. A lower token price does not guarantee a lower cost per correct answer.

Do this today

  1. Choose 20 real, anonymized questions.
  2. Run the same prompt and document through both APIs.
  3. Review citations, refusals, tool arguments, latency, and cost.
  4. Choose one model and record the exact ID and date.
