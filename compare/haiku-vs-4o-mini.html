Claude Haiku 4.5 vs GPT-6 Luna

Compare cost per completed task, not price per token alone.

My verdict: Luna is the lower-cost first run. Haiku stays in the test when extraction nuance or tool behavior matters. The winner is the model with the lower reviewed cost per completed task.

Claude Haiku 4.5 lists $1 input and $5 output per million tokens, 200K context, and 64K maximum output.

Checked28 Sep 2026Source 01

GPT-6 Luna lists $0.10 input and $0.50 output per million tokens, 1.05M context, and 128K maximum output.

Checked28 Sep 2026Source 02

I promote a small model only after it passes extraction and tool-call tests on the same review set.

My takeproduction gate

A fixed cost example

Use a 2,000-token input and a 500-token output. One Haiku call costs $0.0045. One Luna call costs $0.00045. This is call cost, not completed-task cost.

If 80 of 100 Luna runs pass review, divide total Luna spend by 80. If 95 Haiku runs pass, divide Haiku spend by 95. Add retry and human-review cost before choosing.

The measured test

TaskMeasureFailure
ClassificationCorrect labels out of 100Wrong queue or missing review flag
ExtractionExact fields out of 300Invented value or invalid JSON
Tool callingValid calls out of 50Wrong tool, argument, or extra call
LatencyMedian and 95th percentileTimeout or retry
EconomicsTotal spend divided by accepted tasksToken price reported without review cost
PromptClassify the request as billing, sales, or technical. Extract customer_id and requested_action. If either is missing, set needs_review to true. Return valid JSON only.

Do not reuse one model's prompt blindly. Keep the requested schema and grading rules fixed, but allow one documented prompt revision per model.

Do this today

  1. Collect 100 anonymized requests.
  2. Define exact labels and fields before running either model.
  3. Record accuracy, invalid JSON, tool errors, latency, tokens, and review time.
  4. Choose by cost per accepted task.
