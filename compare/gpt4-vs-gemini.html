GPT-6 vs Gemini 3.8 Flash

Current names, prices, context limits, and a task test you can repeat.

My verdict: GPT-6 Sol is my balanced OpenAI starting point. Gemini 3.8 Flash is the price-first Google option in this comparison. Neither wins without a task-specific accuracy and tool-use test.

GPT-6 Astra, Sol, and Luna each list 1.05 million tokens of context and 128,000 maximum output tokens.

Checked28 Sep 2026Source 01

GPT-6 API prices per million tokens are Astra at $10 input and $50 output, Sol at $2 and $10, and Luna at $0.10 and $0.50.

Checked28 Sep 2026Source 01

Gemini 3.8 Flash is $0.75 input and $3.75 output per million tokens through 31 Dec 2026. Its listed 2027 rate is $1.50 and $7.50.

Changing28 Sep 2026Source 02

Personal OpenAI accounts share data for model improvement by default unless the user turns it off. API and Business data is not used for training by default.

Checked28 Sep 2026Source 03

Use one test, not two demos

Create 30 support questions. Ten need exact extraction. Ten need a tool call. Ten cannot be answered from the supplied policy. Review field accuracy, tool arguments, citations, abstentions, latency, and total tokens.

PromptUse the policy and the order_lookup tool. Return JSON with answer, policy_section, order_id, and status. If the policy does not support an answer, set status to needs_review.

Do not combine consumer plan claims with API claims. They have different prices, controls, and data terms. Regional and plan availability can also differ.

Do this today

  1. Build the 30-question set.
  2. Run it on GPT-6 Sol and Gemini 3.8 Flash.
  3. Review errors and cost per accepted answer.
  4. Record the model IDs and test date.
