Claude, overview

6 min readLast checked 2026-09-28

Claude is Anthropic's model family and product surface. For a builder, the useful question is not which model wins a vague benchmark. It is which model has the right capability, context, cost, and operating surface for the task in front of you.

Current API lineup

The checked Claude API lineup is Fable 5.1 (claude-fable-5-1), Opus 5.5 (claude-opus-5-5), Sonnet 5 (claude-sonnet-5), and Haiku 4.5 (claude-haiku-4-5). Fable, Opus, and Sonnet list 1M context and 128K maximum output. Haiku lists 200K context and 64K maximum output.

How I pick a model

I start with Sonnet for a general production task. It has the broad context and output limits of the larger tiers at a lower listed price. That is a starting point, not a rule. Build a small evaluation set that looks like your actual work, then compare the reviewed outcome, latency, tool-call behavior, and total token use.

I reach for Opus when a task needs more careful planning, difficult reasoning, or a costly retry has already shown that a cheaper choice is false economy. I use Haiku for high-volume classification, routing, extraction, or bounded helper work where the prompt and output contract are clear. Fable is a top-tier option to evaluate when the task has a strong reason to justify its price.

Context capacity is not a reason to fill every request with everything you have. Send the instructions and evidence needed for the decision, then test whether retrieval or a compact summary produces a cleaner result.

Plans and product surfaces

Claude's checked plan materials list Free at $0, Pro at $20 monthly or $200 annual, Max starting at $100 monthly with a $200 tier, Team at $25 monthly or $20 annual per standard seat, and Enterprise seat pricing plus API-rate usage with a listed 20-seat minimum. Availability can vary by region and plan.

Checked28 Sep 2026Source 03

The web and app plans are useful for collaborative work, Projects, Artifacts, web search, and Claude Code access where available. The API is the surface to use when your own application needs a controlled, measurable call path. Claude Code is the developer-facing environment for work in a repository or terminal. They share a family name but serve different workflows.

Set up a useful evaluation

  1. Choose ten to twenty representative inputs, including hard cases and failure cases.
  2. Define what a good answer must include, what it must avoid, and who reviews it.
  3. Run the same prompt and tool contract through the candidates.
  4. Record quality, retries, runtime, and token usage, not just a first impression.
  5. Pin a dated ID when consistency matters, and repeat the evaluation before changing models.

This practice makes model selection less like following releases and more like ordinary engineering. The best current choice is the one that meets a reviewed standard for a known cost in your own workflow.
