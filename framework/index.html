Checked My take

A working handbook for building AI that does real work on its own: the models, the protocol that connects them to your tools, the harness that runs them, and the patterns that keep them reliable. Written plainly, checked against the official docs, and dated.

The nine sections are stacked in the order most people learn them. If you are new, read Foundations first; every page after that is written so you can drop in cold. If you run a business and do not write code, the owner track is the better start.

  • Foundations: the vocabulary and mental model. What autonomous AI is and the autonomy spectrum.
  • Claude: the model layer. Current models, prompting for agent work, extended thinking, and tool use.
  • MCP: the open standard that lets a model use your tools and data. Now supported well beyond Anthropic.
  • Plugins: packaged bundles of skills, hooks, agents, and MCP servers for Claude Code.
  • Claude Code: the harness. Settings, permissions, hooks, skills, subagents, and memory.
  • Agent patterns: the blueprints that work, from ReAct loops to evaluation and context engineering.
  • Going autonomous: headless runs, scheduling and routines, self-monitoring, and safety.
  • Build guides: hands-on builds, from a first agent to a skill, an MCP server, and the Agent SDK.
  • Tools: browser automation, desktop control, and running open models locally.

If you notice something wrong or out of date, tell me. Fixes go in the change log.
