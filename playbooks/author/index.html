What this is

This is a working playbook for authors who want to build their own marketing material using Claude. Not theory. Specific prompts, specific templates, specific workflows you can use in the next hour to put out better marketing than you did yesterday.

Who this is for

For fiction and nonfiction authors: book launch, list growth, email, podcast tours, social content, ARC outreach. 15 modules, 60+ prompts.

How the playbook works

Fifteen modules. Each covers one type of marketing asset, with:

  • What the asset does and when to use it
  • The specific prompts you'll run Claude with
  • A worked example you can adapt
  • Compliance notes specific to author
  • A checklist for this week

Plus a prompt library with every prompt in one place.

The order to do them in

  1. Module 1, Why Claude for author marketing
  2. Module 2, Setting up Claude (do this once)
  3. Module 3, The 10 prompt patterns
  4. Modules 4-13, pick whatever asset you need this week
  5. Module 14, The weekly marketing system
  6. Module 15, Compliance checklist
