A few things people ask

Do I need a panel upgrade for a Level 2 charger?

Sometimes. We run the load calculation on your existing panel first. If there's headroom, it's a single new circuit. If there isn't, you'll hear that plainly before any work starts, along with what a panel upgrade would take.

How long does a typical install take?

Most single-circuit charger installs finish in a day. A panel upgrade alongside it usually adds another. Either way, you'll have a firm number before we're on site.

Can you install a charger for a detached garage?

Yes — it usually means a longer conduit run from the panel, which we plan for and quote up front rather than discover halfway through the trench.
