We check the panel before we order the charger

EV Ready Charger Install is a small Long Island outfit built around one idea: a charger is only as good as the circuit and the panel behind it.

Nick Ferraro did general residential electrical work before EVs started showing up in driveways up and down the block. The chargers themselves were rarely the problem — it was what fed them. Panels with no real headroom left, circuits shared with whatever else happened to be nearby, installs done fast to hit a number that never accounted for the dryer and the AC running at the same time.

The fix is boring on purpose: run the load calculation on the actual panel before anything gets quoted, size the circuit for what the house can really carry, and file the permit instead of skipping it because nobody's checking. If the panel's not ready, that's the first conversation, not a surprise once the wall's open.

Everything past that point — the lighting, the troubleshooting, the generator hookup — comes from the same habit: check what's actually there before touching it, and leave a job that doesn't need a callback.

Service area

EV Ready works across Long Island, NY: houses, condos, and small commercial lots. Not sure you're in range? Call and ask — it takes ten seconds, and you'll get a straight answer.
