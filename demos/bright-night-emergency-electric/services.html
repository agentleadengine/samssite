What we fix, and when

Five things cover almost every call. One of them is a true emergency. The rest get booked like any other electrician — just call the same number either way.

Emergency — 24/7

Troubleshooting & repair

What’s included. Dead outlets, breakers that won’t reset, flickering lights, a panel that’s gone quiet, or anything that smells like it’s burning. We trace the fault back to the actual cause instead of swapping parts and hoping it holds.

When you need it. Now, if it’s a real emergency — no power anywhere, sparking, a main breaker that won’t stay on. This is the one line that runs all night.

Scheduled visit

Panel upgrades

What’s included. Old fuse box, or a 100-amp panel with no room left? We run a new 200-amp service, land every circuit properly, and leave a typed directory taped inside the door so you know what each breaker actually controls.

When you need it. The lights dim when the AC or a big appliance kicks on, there’s no slot left for a new circuit, or the panel is older than everything now running through it.

Scheduled visit

EV charger installation

What’s included. A Level 2 charger on its own dedicated 240-volt circuit, run from the panel to the garage or driveway side of the house.

When you need it. We check the load on your existing service first. If there’s room, it’s a single new circuit. If there isn’t, we’ll say so honestly before any work starts, so the charger isn’t fighting the dryer at 7pm.

Scheduled visit

Lighting design & install

What’s included. Recessed cans, dimmers matched to the bulbs going in so they don’t hum, exterior and motion-triggered lighting, fixture swaps, and ceiling fans hung on a fan-rated box instead of a plain plastic one.

When you need it. A remodel, a dark yard at night, a dimmer that flickers on low, or a fixture that was never hung right to begin with.

Scheduled visit

Generator hookups

What’s included. Interlock kits and manual transfer switches so a portable generator feeds the circuits you picked in advance — fridge, sump pump, a few lights — plus whole-home surge protection as a same-visit add.

When you need it. Before the next outage, not during it. If you’re already running extension cords through a cracked window, this is the fix.

How we tell emergency from everything else

Describe what’s happening when you call. No power, sparking, or a main that won’t reset gets a truck moving now. Everything else on this list gets booked like normal work — most of it within a few days, sometimes the same one. Either way, you’ll know which it is before you hang up.

Not sure which one you need?

Describe the problem on the phone and we’ll tell you honestly which of these it is, before anyone drives over.
