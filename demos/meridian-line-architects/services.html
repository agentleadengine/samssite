The full drawing set

Five services, in roughly the order a project actually moves through them — from a site nobody's built on yet to a stamped permit set. If something's outside what we draw well, we'll say so on the phone.

A0

Site Feasibility Studies

What's included
A read on setbacks, lot coverage, and zoning before you buy the lot or commit to a design direction.
When you need it
Before you make an offer, or before you assume an addition is even allowed.

The fastest of the five — usually a short, flat engagement, not tied to a full design.

A1

Custom Home Design

What's included
Site analysis, a first floor-plan concept, elevations, and enough 3D visualization to see the massing before anything is finalized.
When you need it
Buying a lot, or tearing down to start over, and you want the house drawn around the property instead of the other way around.

Fee is scoped after the first site visit, tied to square footage and how much of the design is custom versus standard.

A2

Additions & Renovations

What's included
A design that ties the new roofline, framing, and floor levels into the existing house instead of looking bolted on.
When you need it
A second story, a kitchen bump-out, an in-law suite — anything that changes the footprint or the roof.

Older houses usually need a site visit before we can say what's structurally possible.

A3

3D Concept Visualization

What's included
A massing model and interior views built off the same drawings already in progress, so what you approve is what gets built.
When you need it
Early, while the layout can still change cheaply — not after the walls are framed.

Included in most design work; available on its own for a project already underway elsewhere.

A4

Permit Drawings

What's included
The construction document set a building department actually asks for: plans, elevations, sections, and the notes an examiner needs to approve it without guessing.
When you need it
After the design is settled, before a contractor can pull a permit.

Priced separately if you already have a design from elsewhere and just need it drawn to code.

Not sure which of these your project needs?

Say what you're trying to do. We'll tell you which sheet it starts on.
