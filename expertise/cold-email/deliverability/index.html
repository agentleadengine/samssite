The provider check

  1. Resolve SPF and confirm the lookup stays within the protocol limit.
  2. Send a message and inspect the DKIM signature and DMARC alignment.
  3. Confirm forward DNS, reverse DNS, and TLS for the actual sender.
  4. Use seed inboxes at the providers your recipients use.
  5. Review complaints, bounces, and provider reputation by domain.
Failure example: SPF passes for the workspace, but a separate sender signs with an unaligned domain. The dashboard looks healthy while that stream fails DMARC alignment. Test each real sending path.

Do this today

  1. Send one message through every production path.
  2. Save the authentication results beside the sender name.
  3. Assign an owner for complaint and placement review.
