Multivariate testing

3 min readLast checked 2026-09-28

Multivariate testing varies multiple elements (headline, image, CTA) at once. Reveals interaction effects but requires significant traffic.

When to use

You have enough traffic for 4-8 variants and suspect interactions between variables.

When not

Low-traffic pages where you can barely get one A/B to significance.

Analysis

Statistical models to isolate main effects and interactions. More complex than comparing two numbers.

Plan the cells and interactions

Required sample size depends on cells, baseline, detectable effects, interactions, alpha, power, and analysis. A fixed multiplier over A/B is not sound.

Checked28 Sep 2026Source 01

A four-cell design

Illustrative assumptions: cross headline A or B with a short or long form. The four balanced cells are A-short, A-long, B-short, and B-long. The outcome is qualified_quote_submitted. The model estimates the headline effect, form effect, and headline-by-form interaction.

Suppose the baseline is 8% and the smallest useful main effect is 2 percentage points. With two-sided alpha 0.05 and power 0.80, the same normal approximation used for an 8% versus 10% comparison needs at least 3,211 visitors per factor level. Because each level contains two cells, a balanced plan rounds up to 1,606 visitors per cell, or 6,424 total, for that main-effect target.

Power the interaction as a difference of differences. Assume A-short = 8%, A-long = 8%, B-short = 8%, and B-long = 9%. Use two-sided alpha = 0.05 and power = 0.80. The interaction is (B-long - B-short) - (A-long - A-short) = (9% - 8%) - (8% - 8%) = 1 percentage point.

For equal sample size n in each cell, Var(interaction) = [pAS(1 - pAS) + pAL(1 - pAL) + pBS(1 - pBS) + pBL(1 - pBL)] / n. The numerator is 0.08 × 0.92 + 0.08 × 0.92 + 0.08 × 0.92 + 0.09 × 0.91 = 0.3027.

The normal-approximation formula is n = ceiling[(z1-alpha/2 + zpower)2 × 0.3027 / 0.012]. Substitution gives ceiling[(1.9600 + 0.8416)2 × 0.3027 / 0.012] = 23,759 visitors per cell, or 95,036 total before exclusions.

from math import ceil
from statistics import NormalDist

rates = [0.08, 0.08, 0.08, 0.09]
alpha = 0.05
power = 0.80
interaction = (rates[3] - rates[2]) - (rates[1] - rates[0])
z_alpha = NormalDist().inv_cdf(1 - alpha / 2)
z_power = NormalDist().inv_cdf(power)
variance_sum = sum(p * (1 - p) for p in rates)
n_per_cell = ceil(
    (z_alpha + z_power) ** 2 * variance_sum / interaction ** 2
)

print(f"interaction = {interaction:.3f}")
print(f"variance sum = {variance_sum:.4f}")
print(f"z_alpha = {z_alpha:.4f}; z_power = {z_power:.4f}")
print(f"n per cell = {n_per_cell:,}")
print(f"total = {4 * n_per_cell:,}")
interaction = 0.010
variance sum = 0.3027
z_alpha = 1.9600; z_power = 0.8416
n per cell = 23,759
total = 95,036

This is an approximate planning calculation. Use the planned analysis model for the final design. Sequential single-factor tests can estimate separate headline and form main effects. They cannot establish the headline-by-form interaction because they do not observe all four combinations in one factorial comparison.

Where it breaks: Reading cell rates as independent A/B tests inflates false positives and misses interactions. Unequal traffic, mid-test edits, or sparse cells make the model harder to trust.

Do this today

  1. List factors, levels, and the required interaction.
  2. Set baseline, useful effects, alpha, and power.
  3. Calculate each cell's allocation before launch.
  4. Pre-write the model and comparison rules.
