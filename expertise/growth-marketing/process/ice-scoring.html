ICE scoring

3 min readUpdated 2026-04-19

ICE is a lightweight way to prioritize growth experiments. Rate each 1-10 on Impact, Confidence, Ease. Score = product. Pick highest scores.

Variables

  • Impact: how big if it works
  • Confidence: how sure you are it'll work
  • Ease: how simple to build and test

Usage

Backlog every week. Rank by ICE. Top-scoring tests go first.

Critiques

Subjective scoring. Use for ranking relative priority, not absolute decisions.

Worked ice scoring record

Score impact, confidence, and ease from 1 to 10, then use ICE = impact x confidence x ease.

IdeaEvidenceICEScore
Fix import error38% of failed activations show error E17886384
New welcome videoThree interview requests439108

Illustrative calibration: if five prior ideas scored confidence 8 but only two moved in the predicted direction, future evidence of the same type should receive a lower confidence score.

Where it breaks: Multiplication creates false precision, and teams can inflate scores to favor pet ideas. Compliance and severe reliability work should not wait behind ICE.

Do this today

  1. Score three ideas with evidence links.
  2. Name the decision event and effort owner.
  3. Compare past confidence with readouts.
  4. Recalibrate one unsupported score.
