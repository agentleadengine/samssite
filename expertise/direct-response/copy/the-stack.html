The copywriting stack

7 min readLast checked 2026-09-28

Every piece of direct-response copy that works is working at multiple levels simultaneously, headline, lead, body, close, CTA, P.S., each doing a specific job. Master the stack and you stop thinking about copy as inspiration and start producing it on schedule.

The stack, top to bottom

  1. Write the offer stack (see grand slam offers)
  2. Write the CTA
  3. Write the P.S.
  4. Read the whole thing aloud. Cut anything that makes you cringe.
  5. Show to someone who fits the ICP. Listen to their reactions.
  6. Revise. Ship.

Audit the offer stack

Review every stack element for promised value, evidence, delivery cost, customer use, and overlap. Test a defined stack against the current offer and report net revenue and refunds.

Where it breaks: More listed value can add confusion, fulfillment cost, and unused material.

Do this today

  1. List every component and delivery cost.
  2. Attach evidence for value claims.
  3. Remove one unused component.
  4. Measure contribution and refunds by cohort.
