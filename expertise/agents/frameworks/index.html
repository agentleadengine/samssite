Expertise / AI agents

Choose by state, control, deployment, and migration risk. The logo is the last question.

LangChain agents use LangGraph primitives. Direct LangGraph is the path for deeper control over deterministic and agentic steps.

A two-hour framework test

Build one workflow in the two strongest candidates. It must read a ticket, call a customer lookup tool, draft a reply, pause for approval, and resume after a restart. Save the state schema and trace. Then change the model provider or model ID.

The limitation is upgrade cost. A demo can hide it because nothing has to resume, migrate, or pass an audit. Test checkpoint recovery and one rejected tool call before choosing.

Do this today

  1. Write the five-step ticket workflow.
  2. Choose two frameworks from the matrix.
  3. Test restart recovery, tracing, denied tools, and one model change.
  4. Record package versions and the migration risk you accept.
