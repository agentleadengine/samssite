Google Optimize alternatives

3 min readLast checked 2026-09-28

Google Optimize was the free A/B testing tool. Shut down in September 2023. Here's where to go.

Google Optimize and Optimize 360 ended on 30 September 2023. Google points users to third-party A/B testing integrations, including AB Tasty, Optimizely, and VWO.

Changing28 Sep 2026Source 05

Run a privacy review before the trial

  1. Map each identifier and event from collection to the experiment vendor and every downstream integration.
  2. Record how consent mode changes collection, assignment, storage, and reporting before and after a person makes a choice.
  3. Get written answers for data residency, subprocessors, cross-border transfers, encryption, and breach notice.
  4. Set retention and deletion periods. Test access, correction, deletion, and objection requests with a sample record.
  5. Keep the vendor's answers, contract version, and review date with the implementation decision.

EU and UK data-protection duties depend on the people, data, purposes, transfers, and organizations involved. Ask your lawyer about GDPR, UK GDPR, and EU scope before sending experiment data to a vendor.

Changing28 Sep 2026Source 02

Do this today

  1. Mark whether the first experiment changes browser content, application code, or both.
  2. Request matching quotes with the same traffic, domains, seats, support, and contract term.
  3. Reject any finalist that cannot pass the targeting, exposure, analytics, deletion, and consent tests.
  4. A feature list does not reveal implementation cost. Run the same staging experiment before signing.
