Statistical significance

3 min readLast checked 2026-09-28

Statistical significance compares data with a null model under a predeclared error rate. A p-value of 0.05 is not “95% confidence” that the variant is better.

Do not use a fixed “95% standard.” A p-value of 0.05 is not 95% confidence that a variant wins. Predeclare alpha from the false-positive cost and report the effect interval.

P-value

Under a specified model, the p-value describes how incompatible the observed data are with the null hypothesis. It is not the probability that the result is random or that a variant is better.

Common mistakes

  • Stopping early without a sequential-testing plan
  • Calling 1 minus the p-value “confidence”
  • Running many tests without correction
  • Interpreting non-significance as “no effect”

Set the rule before launch

Choose alpha, power, the smallest useful effect, sample size, duration, and any multiple-comparison correction before reading the result. Report the effect estimate with its interval and business consequence.

Do not choose 90%, 95%, or 99% from a fixed stakes ladder. Choose alpha from the cost of false positives, then plan power for the smallest useful effect.

Do this today

Hypothetical decision brief:

ChoicePredeclared rule
Primary metricCompleted checkout per eligible assigned user
Alpha0.05 for the single primary comparison
Power80% at the smallest useful effect
Smallest useful effect10% relative improvement over the measured baseline
IntervalReport the effect estimate with a 95% confidence interval
Extra metricsRefund and error guardrails, labeled secondary
Multiple variantsUse Holm adjustment when comparing each variant with control

A result can reject the null at alpha 0.05 while its interval still includes effects too small to matter. It can also miss a useful effect when the interval is wide.

Decision rule: Report the estimate and interval. Compare both with the smallest useful change and the guardrails.
