CTA design

3 min readUpdated 2026-04-19

CTA = call to action. The button (or link) where users commit. Design, copy, placement all affect click rate.

Button design

  • High-contrast color
  • Large enough to tap on mobile
  • Clear, readable text
  • One primary CTA per section

Button copy

  • Action-oriented ('Get my plan')
  • Specific over generic ('Start free trial' vs 'Submit')
  • Benefit-laden where possible

Placement

  • Near the promise it completes
  • After evidence for a higher-commitment action
  • Persistent on mobile only when it does not hide content or controls

Testing

Pre-register the copy variants, primary completion event, qualified downstream outcome, sample, and stopping rule.

Do this today

  1. Write the current CTA, the promised next step, and the event that confirms a qualified action.
  2. Hypothetical test brief: Audience: eligible payroll buyers. Control: “Submit.” Variant: “Request payroll review.” Change only the button label. Keep form, offer, traffic, and page constant. Primary metric: submitted forms per assigned eligible user.
  3. Downstream guardrail: sales-accepted leads divided by submitted forms after seven days. Ship only if the completion interval excludes the smallest useful loss and lead quality meets the predeclared floor.
  4. Decision rule: Keep the copy only if qualified completions improve without more reversals or low-quality leads.
  5. Limitation: More button clicks can mean curiosity or confusion, not more completed customer work.
